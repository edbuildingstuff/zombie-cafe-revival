# Phase 4 Session 1: Cafe Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render the player's actual cafe layout from `playerCafe.caf` when `godot/project.godot` boots — floor tiles + walls + furniture in their stored positions, replacing the 27-piece boxer-human grid as the default scene.

**Architecture:** New GDScript class `CafeRenderer` (extends `RefCounted`) consumes the parsed `Cafe` Dict from Phase 3's `LegacyLoader`, walks `Tiles[]` and emits `Sprite2D` children to a parent `Node2D` via three passes (floor → walls → furniture). `main_scene.gd` gains an `assemble(mode: String)` dispatch where `"grid"` preserves the existing boxer-human behavior and `"cafe"` is the new path. The `mapTiles` atlas (currently unpacked) is added to `packGodotAtlases` in `serialization/godot.go`. Floor tile lookup `Tiles[].U1 -> "%d.png"` uses an empirically-cracked LUT with a 45-min budget before Ghidra escalation; ship-with-imperfect is acceptable per the spec.

**Tech Stack:** GDScript 4.x (Godot 4.6.2), Go 1.20+ (`tool/resource_manager/serialization/godot.go` build pipeline), no new external dependencies.

**Spec:** `docs/superpowers/specs/2026-05-10-phase-4-game-tick-design.md` (Phase 4 umbrella + Session 1 detailed)

**Predecessor:** Phase 3 close-out, commit `46ee0f15`. `LegacyLoader.parse_cafe_bytes(data: PackedByteArray) -> Dictionary` is callable. Save round-trip runner is at 207 PASS / 0 FAIL.

```gdscript
func _validate_cafe_render() -> Array:
	# Phase 4 Session 1: load playerCafe.caf via Phase 3 LegacyLoader,
	# render to a Node2D via CafeRenderer, assert sprite counts and
	# textures look right.
	var cafe_path := "res://test/fixtures/save/playerCafe.caf"
	if not FileAccess.file_exists(cafe_path):
		return [cafe_path + ": fixture missing"]

	var bytes: PackedByteArray = FileAccess.get_file_as_bytes(cafe_path)
	if bytes.is_empty():
		return [cafe_path + ": fixture is empty"]

	var cafe_dict: Dictionary = LegacyLoader.parse_cafe_bytes(bytes)
	if cafe_dict.is_empty():
		return [cafe_path + ": LegacyLoader.parse_cafe_bytes returned empty Dict"]

	var tiles_atlas: SpriteAtlas = SpriteAtlas.load_from(
		"res://assets/atlases/mapTiles.png",
		"res://assets/atlases/mapTiles.offsets.json")
	if tiles_atlas == null:
		return ["mapTiles atlas load failed"]

	var furn_atlas: SpriteAtlas = SpriteAtlas.load_from(
		"res://assets/atlases/furniture.png",
		"res://assets/atlases/furniture.offsets.json")
	if furn_atlas == null:
		return ["furniture atlas load failed"]

	# Walls atlas: depending on Task 3 outcome, either an existing atlas
	# or null (placeholder rectangles). Handle both.
	var walls_atlas: SpriteAtlas = null  # Updated in Task 11 if a real atlas is found.

	var node := Node2D.new()
	var atlases := {
		"tiles": tiles_atlas,
		"walls": walls_atlas,
		"furn": furn_atlas,
	}
	var count: int = CafeRenderer.render(node, cafe_dict, atlases)

	# Hard floor: 1925 floor tiles (35x55 grid, one per Tiles[] entry).
	var floor_count: int = 0
	var object_count: int = 0
	for child in node.get_children():
		if not (child is Sprite2D):
			node.queue_free()
			return ["non-Sprite2D child found in CafeRenderer output: " + str(child)]
		var sprite := child as Sprite2D
		if sprite.z_index == CafeRenderer.Z_FLOOR:
			floor_count += 1
		else:
			object_count += 1

	node.queue_free()

	if floor_count != 1925:
		return ["expected 1925 floor sprites (35x55 grid), got " + str(floor_count)]

	# The fixture has 23 non-trivial tiles. Each can carry up to 3 cafe
	# objects (U5/U7/U9), so up to 69. Empirically the fixture has fewer
	# than 30. Use >= 23 as a hard floor; tighten in Session 1.5 if needed.
	if object_count < 23:
		return ["expected ≥23 cafe-object sprites, got " + str(object_count)]

	if count != floor_count + object_count:
		return ["CafeRenderer.render returned " + str(count) + " but children counted " + str(floor_count + object_count)]

	print("  OK cafe render: ", floor_count, " floor + ", object_count, " objects = ", count, " total")
	return []
```
